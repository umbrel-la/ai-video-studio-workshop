# Huashu: камера и GSAP

Если рядом есть `studio-location.json`, прочитай его: `bundle_root` указывает папку полного набора. Все команды ниже запускаются из неё; относительные ссылки разрешай по соответствующему `skills/<имя>/SKILL.md` внутри набора. Если папка перемещена, открой её новый путь и повтори setup в новый каталог скиллов; существующие папки установщик сохраняет.


Сначала прочитай [контракт учебной студии](../../references/motion-v2-contract.md). Этап: Монтаж: камера, фокус и глубина.

Сначала назови объект, который зритель должен прочитать, и причину движения. Выбери push, pan, reveal или статичный hold по `camera-language.md`; реализуй rig по `gsap-recipes.md`. Числа автора — ориентиры, не новые личные требования. Предел масштабирования вычисляй по полному нужному тексту и области экрана.

Камера меняет transform родительского rig, элементы — transform собственных детей. Не назначай CSS и GSAP transform одному элементу. В paused timeline не включай play(), таймеры, requestAnimationFrame или repeat:-1. Используй локальный GSAP из assets; CDN из примеров замени локальным путём до рендера.

Подбирай движение по содержимому: непрерывный наплыв на промпт не заканчивается раньше показа, первая и последняя строки видны; настоящий интерфейс не перерисовывается. Для плотного текста перспектива обычно уступает прямому читаемому виду. Проверяй начало, середину, конец и границы склейки, включая повторный seek.

Не подключай cloud review, Doubao TTS, ARK API, narrate-pipeline или capabilities-сканирование машины из оригинала. Результат: параметры rig в STATE, локальная сцена и кадры крайних положений.
