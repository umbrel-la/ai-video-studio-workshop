# Tegaki: рукописные акценты

Если рядом есть `studio-location.json`, прочитай его: `bundle_root` указывает папку полного набора. Все команды ниже запускаются из неё; относительные ссылки разрешай по соответствующему `skills/<имя>/SKILL.md` внутри набора. Если папка перемещена, открой её новый путь и повтори setup в новый каталог скиллов; существующие папки установщик сохраняет.


Сначала прочитай [контракт учебной студии](../../references/motion-v2-contract.md). Этап: Монтаж: короткая надпись или подпись.

Используй для короткого слова, авторской пометки или подписи, когда рукописный жест помогает смыслу. Субтитры остаются обычным читаемым блоком. Сначала проверь поддержку всех букв выбранным bundle: встроенный Caveat в этом источнике заявлен для Latin, кириллицу не обещай без проверки собственного шрифта и лицензии.

`node scripts/setup-motion-v2.mjs` устанавливает только закреплённые Tegaki/esbuild в `.local/motion-v2` и собирает локальный browser bundle. Рабочий мост и пример — `motion/v2/tegaki-entry.mjs` и техническое демо. TegakiEngine получает `time: {mode: 'controlled', value: 0}`; GSAP меняет числовой proxy, `engine.update({time: {mode: 'controlled', value: proxy.t}})` отрисовывает время. Не используй uncontrolled, autoplay, бесконечный SVG loop или wall-clock callbacks.

Шрифт/JS копируются в assets проекта до рендера; в кадре нет сетевых запросов. Проверка: seek вперёд/назад и повторный кадр дают одинаковое изображение; начало чистое, к концу надпись завершена. Если шрифт не поддерживает текст, используй проверенный локальный bundle или обычный SVG, явно назвав замену.

Результат: редактируемая надпись, локальный bundle, данные о шрифте и проверенные кадры.
