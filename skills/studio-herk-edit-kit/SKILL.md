# Herk Edit Kit: карточки и ритм

Если рядом есть `studio-location.json`, прочитай его: `bundle_root` указывает папку полного набора. Все команды ниже запускаются из неё; относительные ссылки разрешай по соответствующему `skills/<имя>/SKILL.md` внутри набора. Если папка перемещена, открой её новый путь и повтори setup в новый каталог скиллов; существующие папки установщик сохраняет.


Сначала прочитай [контракт учебной студии](../../references/motion-v2-contract.md). Этап: Монтаж: смысловые акценты и библиотека карточек.

Это переименованный nateherkai/hyperframes-student-kit. Используй идеи transcript-driven edits и карточки, сохраняя список исходников, выбранные дубли и STATE текущего проекта. Для поиска есть `node scripts/motion-catalog.mjs search --source herk-edit-kit --query "compare"` и общий каталог source.

Карточка должна объяснять новое или показывать проверенный результат; не дублируй фразу субтитров. Отнеси её к точной реплике и rhetorical role: setup, contrast, mechanism, proof, payoff. Выбирай один приём под задачу; разворачивай горизонтальный шаблон в область 1080×960 или отдельную явно выбранную сцену, а не сжимай весь 16:9.

В комплекте 408 исходников карточек (registry источника заявляет 406) как неисполняемые рецепты и registry; извлечение не делает проект готовым к рендеру. Перенеси нужный markup/timeline, замени demo-copy, все AIS-цвета/знаки/брендовые ссылки, локализуй fonts/assets. Фото, видео и фирменные материалы AI Automation Society не импортированы. Речь не ускоряй; автоматические кандидаты пауз/ошибок требуют просмотра контекста.

ElevenLabs transcribe и загрузка записей не включены. Используй существующую проверенную локальную расшифровку. Результат: выбранные card IDs, речевые якоря, обновлённые сцены и проверка читаемости без дублей.
