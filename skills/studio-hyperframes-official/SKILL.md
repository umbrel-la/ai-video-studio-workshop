# HyperFrames: официальный контракт

Если рядом есть `studio-location.json`, прочитай его: `bundle_root` указывает папку полного набора. Все команды ниже запускаются из неё; относительные ссылки разрешай по соответствующему `skills/<имя>/SKILL.md` внутри набора. Если папка перемещена, открой её новый путь и повтори setup в новый каталог скиллов; существующие папки установщик сохраняет.


Сначала прочитай [контракт учебной студии](../../references/motion-v2-contract.md). Этап: Техническая основа всех сцен и проверка.

Это десятый источник видео: только plugins/hyperframes из openai/plugins, не весь каталог плагинов. В нём пять скиллов; студия предоставляет один совместимый вход, сохраняя их справочные материалы. Пакет plugin объявляет Apache-2.0 и зеркало heygen-com/hyperframes.

Сначала прочитай локальный контракт студии и установленную справку `node scripts/hf.mjs --help`; текущий runtime закреплён на HyperFrames 0.9.30. Советы другой версии не означают наличие команды. Основные правила: timed clips в HTML, root duration, paused timeline по composition ID, локальные media/fonts, никакого wall-clock, autoplay или network во время кадра. Для эффектов сначала ищи доступные registry-компоненты; добавление компоненты требует просмотра её исходника и лицензии.

CLI вызывай через scripts/hf.mjs; установка — scripts/setup.mjs. Сохраняй существующие скиллы и не изменяй закреплённые source-снимки. Внешние capture, transcribe и tts из справочника не запускаются этим скиллом автоматически: для записи интерфейса/голоса существуют материалы проекта, облако требует отдельного поручения на передачу данных.

Результат: совместимый редактируемый проект, реальные check/snapshot/render при необходимости, список фактически выполненных проверок. Готовый MP4 проверяется отдельно от успешного запуска CLI.
