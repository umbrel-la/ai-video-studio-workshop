# Учебная видеостудия

Это вход в полный переносимый набор, а не самостоятельная библиотека шаблонов.

Если рядом есть `studio-location.json`, прочитай `bundle_root` и открой `SKILL.md` и `AGENTS.md` в указанной папке. Если это исходная папка `skills/workshop-studio`, корень набора находится на два уровня выше. Если полный набор не найден, запроси его актуальное расположение: не подменяй каталог другой студией и не обещай наличие рецептов.

Прочитай только нужный маршрут в корневом SKILL. Для существующего ролика начни с STATE его папки. Команды инструментов запускаются из полного набора, а HyperFrames через его обёртку — из проекта участника. Личные материалы остаются в проекте и не копируются в общий набор.
