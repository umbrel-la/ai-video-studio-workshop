# Animated Diagrams: объясняющие схемы

Если рядом есть `studio-location.json`, прочитай его: `bundle_root` указывает папку полного набора. Все команды ниже запускаются из неё; относительные ссылки разрешай по соответствующему `skills/<имя>/SKILL.md` внутри набора. Если папка перемещена, открой её новый путь и повтори setup в новый каталог скиллов; существующие папки установщик сохраняет.


Сначала прочитай [контракт учебной студии](../../references/motion-v2-contract.md). Этап: Сценарий и монтаж: объяснение процесса.

Применяй, когда требуется объяснить связи или последовательность, а запись интерфейса не раскрывает механизм. Схема обозначается как схема, не как реальный экран. Установи узлы, рёбра, смысл потока и фактический источник. Для нескольких узлов достаточно semantic SVG со стабильными node-/edge- ID.

Локальные рецепты: `references/diagram-svg-authoring.md`, `animation-choreography.md`, `gsap-svg-techniques.md`, для крупной схемы `camera-large-flows.md`, для озвучки `voiceover-sync.md`. Покажи контекст, раскрой узлы, проведи связи, выдели текущий шаг, удержи итог. Рёбра рисуй stroke-dashoffset; стрелки отдельными элементами. Для кода выделяй строку синхронно объяснению, без выдуманного результата выполнения.

Создай sub-composition в текущем проекте, а не отдельную систему установки. Локальный GSAP уже есть в runtime студии. Не запускай source setup.sh и автоматическую загрузку Iconify: простые фигуры локальны; реальные логотипы требуют проверенного источника и лицензии. В split-layout схема занимает область экрана; адаптируй размеры и чтение под телефон.

Результат: SVG/HTML и timeline, связь действий с репликами, контрольные кадры всех состояний и доказательство отсутствия обрезанных меток.
