# Учебная студия AI-монтажа

Монтаж собственных записей через Codex, HyperFrames и FFmpeg: камера, экран, отдельный микрофон, субтитры, motion-графика и экспорт MP4 с редактируемым проектом.

Основа — весь публичный набор [ai-video-editing-skills](https://github.com/umbrel-la/ai-video-editing-skills), дополненный десятью motion-модулями, каталогом **569 рецептов**, общим управлением скиллами и состоянием проекта. Репозиторий создан с новой Git-историей. Личные проекты, документы, аккаунты и бизнес-настройки автора не включены.

**Начните с [START-HERE.md](START-HERE.md)** — там готовое сообщение для установки через Codex и первая задача на монтаж.

## Установка и проверка

Нужны Node.js >=22 и npm. Git необязателен: ZIP также подходит.

```bash
git clone https://github.com/umbrel-la/ai-video-studio-workshop.git
cd ai-video-studio-workshop
node scripts/setup.mjs
node scripts/smoke.mjs
```

Setup добавляет отсутствующие скиллы в `~/.agents/skills/`, сохраняет существующие и готовит runtime в `~/.ai-video-editing/`. Локальный Tegaki/esbuild устанавливается в `.local/motion-v2/`. Отчёты с путями не входят в Git. Новые глобальные адаптеры получают локальный указатель на папку набора: **не удаляйте и не перемещайте её после установки без обновления связей**.

Установка не оплачивает сервисы и не даёт доступ к аккаунтам автора. Базовые функции десяти адаптеров и тестовые ролики не требуют API-ключей. Дополнительные media-use, ASR/TTS, генерация и облачные функции исходного набора могут требовать собственных программ, аккаунтов или оплаты. Границы — [API и передаваемые данные](references/api-map-v2.md).

```bash
node scripts/setup.mjs --check
npm test
npm run verify
node scripts/motion-catalog.mjs search --query "compare"
node scripts/motion-variety.mjs motion/v2/plan.example.json
```

Для короткого монтажа можно сразу дать Codex папку с исходниками. Для сценария, съёмки и продолжения — [процесс ролика](references/workflow.md). Создание чистого состояния проекта:

```bash
node scripts/project.mjs init --dir "workspaces/my-first-video" --title "Мой первый ролик"
```

## Исходники, приватность и лицензии

Все файлы публичной основы перенесены; изменения её обвязки отмечены в `IMPORTS.json`. Девять официальных скиллов и их публичные ресурсы проверяются по `UPSTREAM.json`. Новые внешние рецепты — выборочные побайтные снимки закреплённых коммитов в `vendor/motion-v2/`; это не полные клоны десяти репозиториев. Суффикс `.source.txt` исключает их установку как действующих скиллов. Адаптеры направляют нужные приёмы в общий HyperFrames-проект.
