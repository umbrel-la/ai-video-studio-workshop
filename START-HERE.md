# Начало работы

Нужен Codex с доступом к файлам и терминалу на компьютере. Основной набор требует Node.js **22 или новее** и npm. Python для команд этой студии не нужен; отдельные необязательные upstream-инструменты могут иметь свои зависимости.

Скопируйте в новый чат Codex:

```text
Установи мне учебную студию AI-монтажа:
https://github.com/umbrel-la/ai-video-studio-workshop

Скачай её в постоянную отдельную папку. Прочитай README.md,
AGENTS.md и SKILL.md. Проверь Node.js >=22 и npm; используй
исправные установленные программы, недостающие устанавливай
из официальных источников с учётом разрешений системы.
Выполни node scripts/setup.mjs и node scripts/smoke.mjs.
Мои существующие скиллы и настройки не перезаписывай.
Проверь ready и missingBindings в отчёте, покажи тестовый MP4.
Затем объясни, как дать тебе исходники для первого монтажа.
```

Ссылка сама ничего не запускает. Установка скачивает программы и библиотеки, но не устанавливает Codex, не оформляет подписки и не входит в аккаунты. Интернет нужен для зависимостей и первого браузерного рендера. Платные функции требуют собственных подключений участника.

## Ручная установка

```bash
git clone https://github.com/umbrel-la/ai-video-studio-workshop.git
cd ai-video-studio-workshop
node scripts/setup.mjs
node scripts/smoke.mjs
```

Можно скачать **Code → Download ZIP** и распаковать архив вместо Git. Сохраните всю папку студии: новые скиллы используют находящиеся в ней рецепты и инструменты.

Setup устанавливает **21 скилл**: десять из исходного набора, десять motion-адаптеров и входной `workshop-studio`. Существующие папки сохраняются. `preserved` не означает, что их версия совпадает с набором. `missingBindings` показывает адаптеры, связанные с другой студией либо не имеющие связи. При конфликте попросите Codex сравнить версии; установка в новый каталог возможна через `--skills-dir "<новый-каталог>"`. Произвольный каталог нужно отдельно подключить в вашем агенте — сама эта опция не делает его автоматически обнаруживаемым.

Проверить установку без скачиваний и изменений: `node scripts/setup.mjs --check`. Только скопировать скиллы: `node scripts/setup.mjs --skip-tools`; это ещё не готовность к рендеру. Если новые скиллы не видны на следующем сообщении, перезапустите Codex.

## Первый ролик

Создайте отдельную папку и положите в неё записи камеры, экрана и микрофона. Откройте папку в Codex и напишите:

```text
Используй workshop-studio и ai-video-editing из установленной студии.
Проанализируй мои файлы в этой папке. Оригиналы не меняй.
Собери вертикальный ролик примерно на 60 секунд.
Отдельный микрофон — основной голос; синхронизируй его с камерой.
Убери неудачные дубли и лишние паузы, сохрани естественную речь.
Добавь точные субтитры, читаемые приближения интерфейса
и только нужные по смыслу motion-приёмы из каталога студии.
Не выдумывай речь и недостающие кадры.
Сохрани MP4, редактируемый проект и STATE для продолжения.
```

Измените формат, длительность и задачу под свои материалы. Если сценария ещё нет, попросите сначала подготовить точные реплики и план съёмки по [рабочему процессу](references/workflow.md).

## Посмотреть десять приёмов без своих записей

После setup из папки студии:

```bash
node scripts/build-motion-demo.mjs
```

Команда создаст `.local/motion-demo` с синтетическими сценами. Для проверки и экспорта перейдите в этот каталог и вызовите обёртку по абсолютному пути:

```text
node "<путь-к-студии>/scripts/hf.mjs" check --json
node "<путь-к-студии>/scripts/hf.mjs" preview --background
node "<путь-к-студии>/scripts/hf.mjs" render --quality looks -o result.mp4
```

Демо — технические адаптации приёмов, а не обещание, что все исходные примеры десяти авторов воспроизводятся без изменений. Личных записей в нём нет. Повторное создание требует нового `--project` пути: существующий результат сохраняется.
