# Ответственность скиллов

Входной `workshop-studio` находит папку полного набора и читает корневой SKILL. `ai-video-editing` отвечает за монтажный процесс; базовые HyperFrames-скиллы — за проект, медиа, библиотеку блоков, проверку и рендер. Десять дополнительных адаптеров выбираются по конкретной задаче сцены.

| Скилл | Когда применять | Вход → результат |
| --- | --- | --- |
| [studio-reelforge](../skills/studio-reelforge/SKILL.md) | Короткий акцент, типографика, связанный переход | Смысл сцены, реплика, формат → выбранный фрагмент, адаптированная сцена, параметры перехода |
| [studio-tegaki](../skills/studio-tegaki/SKILL.md) | Короткая рукописная пометка | Текст, проверенный шрифт, время → управляемая timeline надпись; кириллица требует проверки |
| [studio-animated-diagrams](../skills/studio-animated-diagrams/SKILL.md) | Объяснить связь или процесс | Узлы, связи, факты, речевые якоря → SVG-схема и поэтапная анимация |
| [studio-motion-sound](../skills/studio-motion-sound/SKILL.md) | Звук к контакту или видимому действию | Геометрия, время и тип события → cue sheet, локальный WAV и onset-report |
| [studio-huashu-camera](../skills/studio-huashu-camera/SKILL.md) | Направить внимание приближением/камерой | Объект внимания, границы читаемости → camera rig и проверенные крайние кадры |
| [studio-herk-edit-kit](../skills/studio-herk-edit-kit/SKILL.md) | Карточка к смыслу фразы | Реальная речь, таймкоды, формат → card ID и адаптированная сцена |
| [studio-motion-library](../skills/studio-motion-library/SKILL.md) | Показать число, сравнение, этапы | Проверенные данные и источник → шаблон диаграммы с реальными значениями |
| [studio-saas-motion](../skills/studio-saas-motion/SKILL.md) | Отдельный проморолик продукта | Аудитория, реальные возможности, сообщение → тема, storyboard, проверка разнообразия |
| [studio-product-launch](../skills/studio-product-launch/SKILL.md) | Непрерывный объект, морф, курсор | Состояния объекта и причинные действия → редактируемая геометрия и timeline |
| [studio-hyperframes-official](../skills/studio-hyperframes-official/SKILL.md) | Уточнить контракт и совместимость | Проект и справка реального CLI → исправления и фактическая проверка |

Явный вызов: «Используй `$studio-tegaki` для короткой подписи». Без специальной команды достаточно описать желаемый результат — агент выбирает скилл по описанию. Все команды адаптеров выполняются из полной папки набора, найденной через `studio-location.json` у установленного скилла.

Поиск: `node scripts/motion-catalog.mjs search --source herk-edit-kit --query "compare"`. `show ID` возвращает проверенный путь; `extract` копирует справочный текст без исполнения. После адаптации укажи source/recipe ID и параметры в STATE проекта.

Не смешивай задачи: создание сценария не запускает облачную генерацию, публикацию или десять эффектов. Основные функции таблицы работают локально; [API](api-map-v2.md) и [контракт](motion-v2-contract.md) описывают границы.
