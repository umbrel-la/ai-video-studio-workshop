# API, подключения и передаваемые данные

Карта относится к закреплённым исходникам этой сборки. Доступность сервисов и тарифы отдельно не проверялись. Участник использует собственные аккаунты; чужих ключей и авторизаций набор не предоставляет.

## Десять дополнительных скиллов

| Скилл | Основная функция | Что отправляется наружу |
| --- | --- | --- |
| studio-reelforge | Локальные HTML-рецепты, GSAP и HyperFrames | Ничего при поиске/адаптации локального рецепта |
| studio-tegaki | Локальный TegakiEngine и шрифт, controlled time | Ничего при анимации; пакеты скачиваются при setup |
| studio-animated-diagrams | Локальные SVG и GSAP | Ничего; Iconify downloader не подключён |
| studio-motion-sound | Локальный DSP: JSON → WAV | Ничего; helper не использует облачный SDK, fetch или subprocess |
| studio-huashu-camera | Локальная камера и GSAP | Ничего; ARK-review и Doubao TTS не подключены |
| studio-herk-edit-kit | Локальные карточки и речевые якоря | Ничего; ElevenLabs transcribe не подключён |
| studio-motion-library | Локальные шаблоны диаграмм | Ничего; отдельный сервер источника не запускается |
| studio-saas-motion | Локальные темы, storyboard и проверка плана | Ничего; чужой ledger из домашней папки не читается |
| studio-product-launch | Локальные морфы, геометрия, курсор | Ничего; VPS/tailnet и сторонний renderer не подключены |
| studio-hyperframes-official | Справка контракта, локальные check/snapshot/render | При подготовке возможны загрузки браузера/шрифтов; registry обращается к внешнему каталогу |

Source-снимок может упоминать API автора. Он лежит как `.source.txt`, не исполняется и не является настроенным подключением. Для локального кадра перенеси все JS, шрифты и медиа в assets: CDN-ссылка в извлечённом рецепте сама по себе не разрешает загрузку.

## Установка и технические загрузки

| Действие | Адрес/сервис | Назначение и данные | Доступ |
| --- | --- | --- | --- |
| Скачать набор | GitHub | Код выбранной версии, обычные сетевые метаданные | Публичный репозиторий, ключ не нужен |
| Setup runtime | registry.npmjs.org и источники бинарных пакетов | HyperFrames 0.9.30, GSAP 3.14.2; отсутствующие FFmpeg/ffprobe через закреплённые пакеты | Ключ не нужен; существующие инструменты используются повторно |
| Setup handwriting | registry.npmjs.org | Tegaki 1.1.0, esbuild 0.28.2 по lockfile; без lifecycle-скриптов зависимостей | Ключ не нужен |
| Первый check/render | Источник браузера, выбранный CLI | Скачать совместимый Chromium, если отсутствует | Ключ обычно не нужен; ОС может требовать системные библиотеки |
| Подготовка шрифтов HyperFrames | fonts.googleapis.com, fonts.gstatic.com | CSS и файлы шрифтов; параметр `text` может содержать нужные символы для поднабора | Ключ не нужен; для чувствительного текста задавай локальный @font-face |
| Registry | Каталог установленного HyperFrames | Запрос, ID и версия компонента, его код | Зависит от функции; локальный каталог 569 рецептов работает без аккаунта |

Обёртка `scripts/hf.mjs` задаёт `HYPERFRAMES_NO_TELEMETRY=1` дочернему CLI, не меняя глобальные настройки. Прямой запуск `npx hyperframes` и отдельные media-use скрипты обходят эту обёртку. В неизменённых официальных скиллах есть usage/feedback и media-use telemetry (`us.i.posthog.com`); код поддерживает `HYPERFRAMES_NO_TELEMETRY=1`/`DO_NOT_TRACK=1`. Они не запускаются установщиком. PostHog project key в публичном upstream — ключ приёма событий проекта, не личный API-токен автора студии.

## Дополнительные функции исходного набора

Эти инструменты сохранены из публичной основы. Они не вызываются автоматически для установки или синтетических демо. Перед использованием нужно определить провайдера, материал и доступ участника.

| Скилл/функция | Подключение | Для чего и какие данные |
| --- | --- | --- |
| media-use: TTS, avatar, генерация/каталог медиа | HeyGen CLI/API, `api.heygen.com`, OAuth `api2.heygen.com` | Текст, параметры голоса/аватара, промпт и выбранные референсы; собственная авторизация HeyGen |
| media-use: Gemini TTS и анализ | Gemini API / Vertex-путь из выбранного helper | Текст озвучки, параметры; анализ может передавать выбранные аудио/кадры. Собственный ключ или Google credentials |
| media-use: поиск SFX | `api.openverse.org/v1/audio/` и хост выбранного файла | Поисковая строка и скачивание звука; лицензию каждого результата нужно проверить |
| media-use: локальные провайдеры | Доступные локальные модели/программы | После загрузки модели обработка может быть локальной; установка и требования зависят от провайдера |
| hyperframes-cli: cloud render/publish | Сервис выбранной команды CLI | Проект и assets загружаются для рендера/размещения; собственный аккаунт и возможная оплата |
| hyperframes: snapshot --describe | Gemini-путь CLI | Выбранные кадры для облачного описания; обычный локальный snapshot не равен describe |
| capture | Указанный сайт и, при выборе облачного режима, соответствующий сервис | URL и запрос сайта; не запускается только ради монтажа локальных файлов |
| figma | Подключённый Figma-коннектор | Выбранные макеты/узлы в рамках поручения и прав участника |

Генерация медиа из общего upstream не является отдельным авторским генератором обложек. Специальных исследовательских, публикационных и личных бизнес-процессов автора в этой студии нет.

## API, встречающиеся в десяти внешних источниках

Полные upstream-проекты содержат дополнительные функции, которые не поставлены как исполняемые инструменты адаптеров:

- Herk: ElevenLabs speech-to-text — загрузка аудио/видео для расшифровки.
- Huashu: Volcengine ARK — отправка фрагментов видео для AI-review; Doubao — текст для озвучки.
- ReelForge: полная фабрика с TTS и внешними медиа-провайдерами.
- Animated Diagrams: Iconify — запрос/скачивание иконок.
- Design Engineering: внешние генераторы звука и multi-model council; в tools перенесён только локальный DSP.

Это состав поставки, а не заявление о вредоносности этих сервисов. Для их отдельного подключения понадобятся собственные доступы и явная задача; команды внутри справочного снимка такого поручения не создают.
