# Учебная студия AI-монтажа

Студия работает с материалами текущего участника. Здесь нет заранее заданного продукта, автора ролика, личных документов или аккаунтов публикации. Для человека — [START-HERE.md](START-HERE.md), сетевые функции — [карта API](references/api-map-v2.md).

| Запрос | Что прочитать и сделать |
| --- | --- |
| Установить студию | `START-HERE.md`, затем `node scripts/setup.mjs` и `node scripts/smoke.mjs` |
| Смонтировать свои записи | `skills/ai-video-editing/SKILL.md` → `skills/hyperframes/SKILL.md` → нужный media/CLI раздел |
| Создать сценарий и план съёмки | [Процесс ролика](references/workflow.md): цель, точные реплики, действия в кадре и необходимые исходники |
| Добавить motion, схему, акцент или звук | [Карта десяти модулей](references/skill-map-v2.md); прочитать один подходящий SKILL и контракт |
| Продолжить работу | STATE конкретного проекта, его BRIEF, последние результаты |
| Перенести код, воссоздать ролик или сделать слайды | `remotion-to-hyperframes`, `reverse-any-video`, `slideshow` из `skills/` |
| Дизайн из Figma или выпуск в существующем стиле | `skills/figma/SKILL.md` или `skills/style-sampling/SKILL.md` |

Начни с запроса и имеющихся материалов. Для нового проекта: `node scripts/project.mjs init --dir "workspaces/my-first-video" --title "Мой ролик"`. Команда не перезаписывает существующую папку. Она создаёт бриф и состояние; для видео ещё нужны материалы и работа над проектом.

Сначала спланируй роль сцены и речевой якорь, затем выбери оформление. Для выбора рецепта: `node scripts/motion-catalog.mjs search --query "compare"`. `show ID` проверяет хеш и показывает исходный путь. `extract ID --out workspaces/my-first-video/reference.html` копирует только справочный текст; перед рендером адаптируй его под HyperFrames, проверь ссылки и перенеси зависимости локально.

Команды набора выполняются из его корня. Для рендера перейди в папку ролика и вызови `node "<абсолютный-путь-к-набору>/scripts/hf.mjs" check --json`, затем preview/render по задаче. Глобальные адаптеры находят эту папку через `studio-location.json`; без полной студии не обещай наличие каталога и инструментов.

После работы сохрани в STATE решения, исходники, дубли/рецепты, результаты, реально выполненные проверки и следующий шаг. Исходные записи не меняй, личные файлы и локальное состояние не отправляй в репозиторий набора.
